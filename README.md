# Мій напрям — профорієнтаційний проєкт КПІ

Це демонстраційний статичний сайт для знайомства з професіями, проходження профорієнтаційного опитування та перегляду факультетів, навчально-наукових інститутів і спеціальностей КПІ.

## Як відкрити локально

1. Розпакуйте архів.
2. Відкрийте файл `index.html` у браузері.
3. Файл `tarot-orb.png` має залишатися поруч з `index.html` — він використовується у вкладці «Гадання».

## Як опублікувати на GitHub Pages

1. Створіть на GitHub новий репозиторій з назвою, наприклад, `mii-napriam-kpi`.
2. Зробіть його `Public`.
3. На сторінці репозиторію відкрийте вкладку `Code`.
4. Натисніть кнопку `Add file` над списком файлів, потім виберіть `Upload files`.
5. Розпакуйте цей ZIP на комп’ютері. Перетягніть у вікно GitHub саме три файли з папки: `index.html`, `README.md` і `tarot-orb.png`. Не перетягуйте сам ZIP і не завантажуйте папку, всередині якої вони вкладені.
6. Унизу сторінки натисніть `Commit changes`.
7. Відкрийте `Settings` → `Pages`.
8. У `Build and deployment` виберіть `Deploy from a branch`, гілку `main` і папку `/ (root)`, потім натисніть `Save`.
9. Після завершення публікації GitHub Pages покаже адресу на кшталт `https://ВАШ-ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/`.

## Як оновити сайт у вже створеному репозиторії

1. Відкрийте вкладку `Code` → `Add file` → `Upload files`.
2. Завантажте новий `index.html` та `tarot-orb.png` з цього архіву. Якщо GitHub запитає підтвердження заміни однойменного файлу — підтвердьте.
3. Натисніть `Commit changes`. GitHub Pages оновить сайт автоматично.

- Проєкт є демонстраційним і не є офіційним сайтом КПІ.
- Фото у картках підрозділів — тематичні ілюстрації, а не обов’язково реальні фото конкретних факультетів або корпусів.
- Вкладка «Професії» містить загальний каталог спеціальностей України за галузями та окремий перелік найпопулярніших спеціальностей за кількістю заяв. Каталог подано для ознайомлення; актуальні умови вступу перевіряйте на офіційних ресурсах.
- Актуальність програм, набір і правила вступу потрібно перевіряти на офіційних ресурсах: https://vstup.kpi.ua/ та https://osvita.kpi.ua/op.
